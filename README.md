# BMI Calculator 🐍

A beginner-friendly BMI Calculator developed using Python.

## About the Project

This project calculates Body Mass Index (BMI) using the user's weight and height.

It displays the calculated BMI and its corresponding category.

## Features

- Accepts weight in kilograms.
- Accepts height in meters.
- Calculates BMI.
- Displays BMI rounded to 2 decimal places.
- Classifies results into categories.
- Handles invalid inputs.
- Includes error handling.

## Technologies Used

- Python 3
- Conditional Statements
- Variables
- User Input
- Exception Handling

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python bmi_calculator.py
```
